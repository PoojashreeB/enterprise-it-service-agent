TITLE: Password Reset Guidance

CATEGORY: PASSWORD_RESET

PURPOSE:
Provide safe guidance for users who need to reset their
corporate password.

--------------------------------------------------
FORGOTTEN PASSWORD
--------------------------------------------------

1. Open the organization's approved password reset portal.
2. Select the password reset option.
3. Enter the required corporate account information.
4. Complete the organization's identity verification process.
5. Complete MFA verification if requested.
6. Create a new password according to corporate password requirements.
7. Sign in again using the new password.

--------------------------------------------------
PASSWORD EXPIRED
--------------------------------------------------

1. Use the organization's approved password management portal.
2. Follow the password change instructions.
3. Complete identity verification if requested.
4. Create a new password that satisfies corporate requirements.
5. Sign in again using the new password.

--------------------------------------------------
PASSWORD RESET FAILURE
--------------------------------------------------

If the password reset process fails:

1. Record the error message.
2. Verify that the correct corporate account is being used.
3. Retry using the approved password reset portal.
4. Contact the IT Service Desk if the problem continues.

--------------------------------------------------
SECURITY GUIDELINES
--------------------------------------------------

- Never share your password with anyone.
- Never provide MFA codes to another person.
- Do not send passwords through email or chat.
- Do not use unauthorized password reset websites.
